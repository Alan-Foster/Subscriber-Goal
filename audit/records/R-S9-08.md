# R-S9-08: Job runner results and lock contention don't reach the logs

## 1. Current Implementation

dispatchDueJobs returns a map of results (complete, retry, exhausted, not_due), but dispatchScheduledJobs and dispatchOnboardingJob discard it. A worker whose lock is busy returns not_due with no log. Only exhaustion, budget deferral and thrown errors are logged.

## 2. Problem and evidence

A job retrying every minute (status retry) is visible only once it's exhausted. With the cron run summary from #255, the parent action shows as 'ran' with no detail.
