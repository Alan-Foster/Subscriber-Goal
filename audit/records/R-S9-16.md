## 1. Current Implementation

Four decoders parse JSON, check the fields, and return undefined when the shape doesn't match, without logging. The caller then behaves as if no record exists.

## 2. Problem and evidence

Parse exceptions are logged by the surrounding catch, but valid JSON with missing or wrong fields falls through to return undefined. For a deletion intent, that silently drops a pending deletion or verification. For pending tracking, a join's tracking repair never happens. For acceptance evidence, an expired record and a malformed one look identical.
